# Vostok Labs Design System: Noir-Tech

## Core Identity
- **Atmosphere:** Industrial, dark, laboratory-grade.
- **Colors:** 
  - Background: `#010101`
  - Primary Accent: `#39FF14` (Vostok Green)
  - Secondary Accent: `#06b6d4` (Cyan)
  - Text: `slate-400`, `white`

## UI Elements
- **Glassmorphism:** `bg-white/[0.02] border border-white/10 backdrop-blur-md rounded-3xl shadow-2xl`.
- **CRT Effect:** `linear-gradient(rgba(18, 16, 16, 0) 50%, rgba(0, 0, 0, 0.2) 50%)`, background size `100% 4px`.
- **Typography:**
  - **Data:** `JetBrains Mono`, weight `900`.
  - **Interface:** `Inter`, weight `400-800`.
  - **Titles:** `uppercase`, `tracking-[0.4em]`.

## Canvas Patterns
- **Grid:** rgba(255, 255, 255, 0.02) linear gradients.
- **Bars:** `hsla` gradients (Cyan to Blue/Lime).
- **Interactive:** Neon Laser Crosshair (#39FF14), Floating Noir Tooltips.
